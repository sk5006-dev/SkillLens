# SkillLens — Career Execution & Growth Intelligence Platform

SkillLens is an enterprise-grade career growth intelligence platform designed to help engineers analyze resume readiness, track skill gaps, map role targets, manage project portfolios, and execute weekly roadmaps with data-driven evidence.

---

## 🌟 Core Features

- **Dashboard Intelligence**: Real-time readiness scoring, target gap breakdown, and high-impact action recommendations.
- **Resume Intelligence**: Structural scoring, section health, bullet impact metrics, and AI improvement recommendations.
- **Project Portfolio Management**: GitHub repository integration, project readiness scoring, and skill extraction.
- **Role Target Intelligence**: Target company and role benchmarks, match breakdown, and skill gap visualization.
- **Roadmap Execution Workspace**: Weekly milestones, verification proof tracking, and target readiness progression.
- **Growth Intelligence**: Historical skill progression, category breakdown, verified milestone evidence log, and progress metrics.
- **Workspace Control Center (Settings)**: Profile management, career objectives, synchronization triggers, notification preferences, privacy controls, and data management.

---

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, Vanilla CSS design tokens, Lucide Icons, Framer Motion
- **3D Graphics**: Three.js / React Three Fiber
- **State Management**: Zustand (Deterministic persistence)
- **Charts & Visualizations**: Recharts

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sk5006-dev/SkillLens.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
